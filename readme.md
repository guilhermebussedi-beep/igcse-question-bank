# IGCSE Maths 0607 Question Bank

A static question bank website for the IGCSE Mathematics (0607) curriculum, hosted on Cloudflare Pages.

## Overview

This site serves as an interactive question bank for students and teachers following the Cambridge IGCSE International Mathematics (0607) syllabus.

## Technology

- Plain HTML/CSS/JavaScript — no build step required
- Hosted as a static site on Cloudflare Pages
- Question/mark-scheme images live in `images/` and are served directly by Cloudflare Pages

## Running Locally

Open `index.html` directly in a browser, or serve it with any static file server:

```bash
npx serve .
```

## Deployment

Deployed automatically via Cloudflare Pages. Any push to the main branch triggers a new deploy.
